## Pre-analysis specification

The frozen specification's Section 18 names `R60` as the outcome, `log1p_VA` as the exposure, and the six controls: volatility, normalized box width, breakout strength, pre-breakout trend, breakout direction, and UTC hour. Before examining the regression results, the Decisions Log recorded ordinary OLS with HC3 heteroskedasticity-consistent standard errors. The specification remains unchanged.

Formula:

`r_60 ~ log1p_VA + volatility + normalized_box_width_atr + breakout_strength + pre_trend + C(breakout_direction) + C(hour_of_day_utc)`

The sample was complete cases among `primary_analysis_eligible` rows, requiring finite `r_60` and all listed predictors. `breakout_direction` and `hour_of_day_utc` were categorical; all observed levels, including all 24 UTC hours, were retained. Confidence intervals and p-values use the HC3 covariance with a t reference distribution (`use_t=True`). `r_60` is a decimal return, not a percentage.

## Input and design checks

- Input table: 324 rows, 324 unique non-null event IDs.

## Results

For the primary exposure `log1p_VA`, the OLS coefficient was **−0.0015176** (HC3 SE **0.0027117**), with a 95% t-based confidence interval of **−0.0068563 to 0.0038211** and **p = 0.5762**. The interval includes zero; this model does not show clear evidence of an adjusted linear association between `log1p_VA` and 60-minute return in this sample. In return units, the point estimate is about −0.152 percentage points per one-unit increase in `log1p_VA`, with a wide interval.

- R² = **0.06284**; adjusted R² = **−0.03782**.
- Coefficients, HC3 standard errors, 95% confidence intervals, and p-values for every fitted term are in `07 Results/tables/r60_ols_hc3_2026-11-09-01.csv`.

## Limitations and scope

This is an observational, single-instrument, single-exchange pilot result, not a causal estimate. HC3 adjusts the estimated covariance for heteroskedasticity; it does not address omitted confounding, functional-form misspecification, or dependence between events. This run did not conduct additional residual diagnostics or multiplicity correction. The coefficient for `log1p_VA` is imprecise and does not establish either a positive or negative association.

Only this R60 OLS model was fitted. Cox was not re-estimated. Spearman, project tests, alternative estimators, and aggTrades analysis were not run.
