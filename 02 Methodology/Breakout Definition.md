# Breakout Definition (Pilot v0.1)

## Base Specification

Свеча $t$ проверяется на пробой относительно параметров Consolidation Box ($H, L$), построенного по свечам $t-32 \dots t-1$.
Используется 15-минутный $\text{ATR}(14)$, рассчитанный по методу Wilder с использованием данных строго до $t-1$ включительно.

- **Upward Breakout:**
  $$\text{Close}[t] > H + 0.1 \times \text{ATR}[t-1]$$
- **Downward Breakout:**
  $$\text{Close}[t] < L - 0.1 \times \text{ATR}[t-1]$$

## Timing and Measurement Start

- Событие фиксируется строго в момент закрытия свечи $t$.
- Измерение всех последующих результатов начинается строго после закрытия пробойной свечи $t$ (с точки $\text{Close}[t]$).
- Движение внутри пробойной свечи $t$ не считается последующим результатом.
- Не требуются: ретест, подтверждение следующей свечой, аномальный объём пробойной свечи, POC, LVN/HVN или обязательное продолжение. Ложные пробои сохраняются в выборке.
- Фильтр «не менее 50% тела свечи за границей» в Pilot v0.1 не используется.
