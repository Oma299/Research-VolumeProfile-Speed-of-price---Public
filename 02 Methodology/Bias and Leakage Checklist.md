# Bias and Leakage Checklist (Pilot v0.1)

Перед каждым анализом проверить:

- [ ] Границы Consolidation Box ($H, L$) рассчитаны только по завершённым барам $t-32 \dots t-1$.
- [ ] Относительная ширина $w$ сравнивается с процентилем только по окнам, полностью завершившимся до текущего кандидатного окна (нет заглядывания в будущее).
- [ ] Volume Profile построен по 1-minute барам за предыдущие 30 дней и заканчивается строго до пробойной свечи $t$ (свеча $t$ полностью исключена).
- [ ] 15-минутный $\text{ATR}(14)$ по методу Wilder рассчитывается по данным строго до $t-1$.
- [ ] Квантили и квинтильные группы Volume Ahead не оценивались по всей выборке с использованием будущего тестового периода.
- [ ] Параметры детектора и порогов не подбирались под подтверждение гипотезы.
- [ ] Нет survivorship bias в Binance BTCUSDT Spot данных.
- [ ] Неудачные, ложные и цензурированные события не удаляются из выборки.
- [ ] Жизненный цикл box (активен макс 32 свечи, без перекрытий) соблюден строго.
- [ ] Часовые пояса (UTC) и торговые сессии согласованы.
- [ ] Train/validation/test разделены по времени (для полного исследования, с embargo 30 дней).
- [ ] Любое исключение события (например, missing VA, вырожденный ER) имеет записанную причину.
